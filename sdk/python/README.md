# nurgling — Python bots for the Nurgling2 client

The SDK for the Nurgling2 client's scripting API. It has no dependencies (stdlib only, Python 3.9+).

The client ships this package and puts it on `PYTHONPATH` for scripts it launches from its Scripts menu.
Install it yourself only to attach from an IDE or notebook:

    pip install nurgling

Documentation: https://aleksandrsvoboda.github.io/nurgling2/latest/
